And the small things that add up.

Launch Studio too

Play and Studio each get their own versions folder. Move either one to any drive you like.

Works from the website

Huistrap registers as the roblox-player handler, so joining a game from roblox.com opens it through Huistrap.

You choose when Roblox updates

Every launch, decide whether to update Roblox first or start the version you already have.

Accounts stay encrypted

Saved login cookies are encrypted with your Windows account through Electron's safeStorage.

Executor status

Pick an executor and see its update status from WEAO on the home screen.

Community on Discord

Ask questions, share flags and hear about releases first.

Up and running in a minute.

Download

Get Huistrap.Setup.1.4.0.exe from the latest release.

Install

Choose an install folder. Desktop and Start Menu shortcuts are created for you.

Launch Roblox

Open Huistrap and press Download & Launch. Next time, it launches the installed version.
